Prototype scope
What is built and running today vs. what is planned
Implemented in this prototype
  • Hosted server runs the engine; official sign-in with session cookie
  • Crowd reports per location (typed in) trigger a full recalculation
  • Rerouting keeps each crowd heading to its destination (Lalbaug, then Girgaon): staging and onward moves only, never away from the goal
  • Volunteer deployment (police, medics, crowd control) by pressure, with shortfall shown
  • Closing a location, link throughput limits, escalation when nothing safe is left
  • Bin fill, time-to-full and truck dispatch; editable JSON profile; JSON export
Future scope (not built)
  • Automatic counts from sensors, CCTV or ticketing (reports are typed today)
  • Individual volunteer accounts, rosters and live locations; per-role logins
  • Database, audit log and multi-user live updates
  • Crowd forecasting from past festival data and per-crowd destination mix
  • Globally optimal routing (min-cost max-flow) and real travel times
  • Release timing for held crowds; alerts pushed to field staff
